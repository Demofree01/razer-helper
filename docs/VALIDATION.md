**Tested only on one Razer Blade 14 (2025), RZ09-0530. Another unit of the same model, similar models, or different machines are not guaranteed to work. Hardware validation excludes advanced writes, native Fn/Hypershift triggering, and untested target applications.**

完整使用说明：[中文](../README.md) / [English](../README.en.md)。问题可随时在 [Issues](https://github.com/Demofree01/razer-helper/issues) 留言。

## 离线验证

1.1.1 的测试程序通过 **120 项测试，零失败**。普通测试使用模拟硬件、CPU 策略、输入、外部动作及剪贴板，不向实际用户窗口发送按键／鼠标，不运行用户命令，不应用进阶参数。

覆盖报文和接口布局、允许列表、模式与供电限制、部分失败回退、持续／瞬时不一致、背光门控、显示策略、XML 安全解析、宏顺序／循环／嵌套／授权、取消与输入释放、容量上限、LevelDB SST／WAL／Snappy／CRC、删除记录优先、Windows 模式覆盖策略、NVIDIA N/A 门控、Fn 信号有效期，以及 1.1.1 的 Unicode 文本转换和绑定当前编辑保存回归。

宏回归验证检查接收器实际收到文本的 Unicode 按下／释放和相邻按键，导入文本不调用剪贴板；旧宏仅在来源 ID 与动作精确一致时修复，已编辑或歧义来源不覆盖。**模拟输入被接收不代表目标应用一定会处理。**

四个主页面和新增对话框使用示例状态渲染检查，未启用真实扫描、Fn 监听或自动硬件策略。

## 运行占用与限制

一次托盘空闲样本约 54 MB 工作集，约 195 秒内 CPU 累计用时没有增加，无 TCP 连接。该样本不是持续性能承诺；打开界面、启用策略或执行宏时占用会变化。

没有为验证而强制锁屏、休眠、制造物理断电、安装内核驱动或调用雷云 AMD 超频组件。进阶参数、睡眠唤醒、原生 Fn／Hypershift、真实宏目标应用和未测试机型仍需要进一步人工验证。

原始开发快照和本机配置位于被忽略的 `artifacts/`，不随源码或便携发行包公开。可用 `scripts/build.ps1 -Tests` 重跑离线测试；诊断分享前检查并脱敏本机信息。
