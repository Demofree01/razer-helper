# 1.1.1 离线宏、只读迁移与 Fn

宏动作由 Helper 本地执行，没有联网、雷云界面或云账号依赖。真实 Fn / Hypershift 触发尚未完整实现，测试机未确认可靠的独立 Fn 信号，请使用 Ctrl+Alt。详细日常使用说明见 [中文](../README.md) / [English](../README.en.md)。

1.1.1 修复雷云文本动作的转换：雷云 `clipboard` 事件表示输入指定文本，1.1.0 错误地转换成只写剪贴板，导致显示完成但目标没有文字。现在转换为 Unicode 直接输入，保留相邻按键与延迟，不访问剪贴板。旧版已导入宏只有在 ID 和全部事件与只读雷云快照精确一致时才可修复；已编辑或来源不明的宏保持原样，保存前保留完整配置备份。不会自动播放或启用快捷键。

绑定窗口的“保存并生效”会保存当前编辑选项，新增或修改单个绑定无需先加入草稿列表。启用绑定前检查宏的权限和结构；未校准 Fn 时默认选择 Ctrl+Alt。宏页完整显示播放状态，失败原因写入日志，文本内容与命令参数不写入日志。手动播放有 3 秒倒计时，需切换至目标输入框；仍停留在 Helper 时停止输入。

## 从本机雷云迁移

1. 在“宏”页点“只读扫描雷云宏”。程序使用共享只读句柄读取本机 Chromium Local Storage 与宏日志，校验 LevelDB 的 SST / WAL / Snappy / CRC，不打开数据库锁、不恢复数据库、不写雷云文件。当前缓存的删除记录优先，不用旧日志复活已删除的列表。
2. 先查看来源时间和步骤。缓存或日志可能只包含历史快照，不保证与当前雷云界面一致。空宏、未知动作拒绝导入，默认隐藏文本内容和命令参数。候选数量取决于本机数据，不预设固定宏列表。
3. 勾选需要的候选，点“导入勾选宏”。不会自动播放、绑定或开启外部动作。已有同一 ID 不覆盖；空宏或未知动作使整批选择拒绝，避免静默丢失步骤。
4. 在“编辑所选宏”中检查录制延迟、按钮、坐标与目标程序。剪贴板、启动 / 命令需由你在对应宏设置中允许；调用它们的外层宏也需允许。先核对后再在单独绑定页启用。

本机当前可转换记录含键盘扫描码、HID usage、延迟、剪贴板文本和鼠标移动 / 按钮。扫描码标志的 0 / 1 是按下 / 释放，2 / 3 带扩展标志；HID 事件的 flag 1 / 0 则是按下 / 释放，两者不能混用。鼠标事件 ID 的成对映射和绝对坐标留待人工核对，未实际发送测试点击。雷云 `mouseMoveType=none` 时，即使旧轨迹仍在事件列表，也按原配置不启用移动。

只读绑定日志只展示参考记录，可能过时，不据此自动设置。支持的文件导入包括本程序 JSON、识别到的雷云 4 `appEngine.events` 单宏 JSON，以及常见 Synapse XML 键盘 / 鼠标格式。雷云 3 / 4 导出格式可能不同，未知事件拒绝；不承诺所有历史导出格式通用。

## 编辑与执行

| 动作 | 行为 |
|---|---|
| 延迟 | 毫秒等待；其他动作也可设动作前延时 |
| 键盘 | 单独按下 / 释放、扩展扫描码；可在编辑窗口捕获一个键 |
| 鼠标 | 五个按钮、滚轮、相对移动 / 绝对桌面坐标 |
| 文本 | Unicode 直接输入，默认预览隐藏内容 |
| 剪贴板 | 允许后只写文本，不自动粘贴；仅在原内容可按纯文本恢复时执行，粘贴需另加按键 |
| 嵌套宏 | 引用本地宏；检查缺失引用、环和一致的目标 EXE |
| 循环 | 1–1000 次，子动作可继续嵌套 |
| 启动 | 指定绝对路径 EXE 与参数；可打开正常程序窗口 |
| 运行命令 | 指定绝对路径 EXE 与参数，后台启动；不自动拼接 shell |

宏设置与动作编辑采用草稿，取消不会改变原宏。文本、命令参数需主动勾选显示后才能看到；导出 JSON 和你手动导入后保存的本地配置会包含这些实际数据。诊断输出和运行日志不记录文本或命令参数。AI 改写 / 总结等云模板没有实现。

最多 64 个宏，单宏含子动作最多 4096 个，嵌套最多 8 层，展开最多 100000 个动作，运行上限 1–600 秒。播放前先完整展开和校验，不会执行前半段后才发现循环或无授权命令。F12、焦点变化、锁屏、运行超时和输入失败会停止，并释放本次模拟按下的键 / 按钮。不会自动提高程序权限。

剪贴板结束后约 300 ms 尝试恢复原值，退出 Helper 时也尝试恢复。如果期间发生新的复制，即使文本相同也不会覆盖它；以剪贴板序列号检查所有权。复杂非文本原内容会拒绝写入。异步粘贴特别慢的应用，可在粘贴动作后加延迟再结束宏。启动程序导致前台窗口变化时停止后续输入；运行命令不代表无限等待进程退出。

原有手动录制仍只记录键盘、按钮和滚轮，最多 60 秒，Esc / F12 停止。鼠标轨迹通过迁移或手动编辑设置，不在普通录制中持续采集。

## 分开的按键绑定与 Fn 校准

在“按键绑定 → Hypershift / 自定义组合键”选择宏与按键，设定播放一次、指定次数、按住播放或再次按下停止，勾选“启用此绑定”，点击“保存并生效”。默认不启用。编辑多个绑定时，可用“保存为新绑定”将它们加入列表，最后保存并生效。Ctrl+Alt 绑定支持一次 / 次数和再次按下停止，需释放修饰键后才注入输入；按住播放只提供给 Fn。

Fn 不是普通 Windows 修饰键。本机 vendor usage 0x59 的 MI_03 接口输入长度为 0，只支持 feature 数据，不能当作可读 Fn 输入流。Helper 可以观察本机键盘、消费者控制及系统控制集合的原始报文，但没有为读取 Fn 写设备模式、重映射键位或安装过滤驱动。

手动测试顺序：

1. 在雷云托盘正常退出雷云；保持原设备模式，不为了测试启用未知驱动模式。
2. 打开“识别 Fn 信号”，只按下和放开 Fn，至少重复两次。左侧选择按下、右侧选择释放报文，两者需来自同一内置键盘、各出现至少两次且不同。
3. 若单独 Fn 没有报文，取消识别，保持 Fn 绑定未启用。此状态无法独立获取 Fn；可先用 Ctrl+Alt 触发同一离线宏。普通 Z、X 或方括号输入不应被当作 Fn 信号。
4. 有稳定信号时保存，启用一个短测试宏的 Fn 绑定，保存全部，再测试 Fn+对应键。识别信号有 2 秒有效期，释放或过期清除；按住播放也随信号过期停止，避免信号丢失后继续运行。其他设备、模拟输入和普通按键不会匹配未经校准的 Fn 绑定。

这项尚需真实按键结果验证，不属于已测试通过的功能。本机雷云的映射模块另有 `IsHypershiftActive` 等原生接口，加载及初始化该引擎可能启用设备钩子或映射；开发时只读查看模块入口，没有调用它，也没有把其他键盘型号的报文假定为本机协议。
