## 中文

轻量、离线的 Windows 托盘助手，支持键盘基本灯效、Blade 性能预设、固件 CPU／GPU 档位、Windows 电源模式、内屏刷新率、80% 充电保护和本地宏。

**仅在雷蛇灵刃 14 2025 款（RZ09-0530）上测试通过。同型号、同类型及其他机器均不保证可以运行成功。进阶参数写入与真实 Fn／Hypershift 触发尚未完成实机验证。遇到问题或有建议可随时在本仓库 Issues 留言。**

下载 `RazerHelper-1.1.1-win-x64.zip`，完整解压并运行 `RazerHelper.exe`，保留相邻 `.config`。需要 Windows x64／.NET Framework 4.8。主界面关闭后留在托盘，托盘“退出”结束程序。中英文详细使用说明随包提供，仓库首页也可查看。

- 1.1.1 修复雷云文本宏只写剪贴板、未输入文字的问题，导入文本改为 Unicode 直接输入。
- 按键绑定“保存并生效”提交当前编辑，宏页显示完整播放结果；手动播放有三秒切换目标窗口时间，F12 停止。
- 雷云宏只读扫描、预览后手动导入，不自动播放或开启绑定。Fn／Hypershift 尚未完整支持，请先用 Ctrl+Alt。
- 进阶 CPU 策略仅手动应用；CPU 精确瓦数／降压、风扇曲线、MUX 等未实现。测试机 GPU 当前上限 N/A，瓦数设置禁用。
- 120 项离线测试通过；宏输入、进阶写入和故障回退使用模拟接口，不等于所有目标应用或硬件已验证。

包内不含开发机配置、宏、密码、日志或诊断快照。宏内容在本地配置和导出中明文保存，请勿上传带密码的宏文件。

## English

A lightweight offline Windows tray helper for basic keyboard lighting, Blade performance presets, firmware CPU/GPU levels, Windows power modes, internal refresh rates, 80% charge protection, and local macros.

**Tested only on the Razer Blade 14 (2025), RZ09-0530. Operation is not guaranteed on another unit of the same model, similar models, or different machines. Advanced writes and native Fn/Hypershift triggering are not hardware-validated. Questions and feedback are welcome at any time in this repository's Issues.**

Download `RazerHelper-1.1.1-win-x64.zip`, extract it completely, and run `RazerHelper.exe` with its adjacent `.config`. Requires Windows x64/.NET Framework 4.8. Closing the window leaves it in the tray; use tray Exit to quit. Detailed Chinese and English guides are included and available on the repository homepage. The UI is currently Chinese.

- Fixes Synapse text macros that only changed the clipboard: imported text now uses direct Unicode input.
- Save and activate commits the current binding edit. Full playback status is visible; manual playback gives three seconds to focus the target. F12 stops playback.
- Synapse migration is read-only scan, preview, then manual import. No automatic playback or enabling bindings. Fn/Hypershift is incomplete; use Ctrl+Alt.
- Advanced CPU policies apply only manually. Exact CPU watts/undervolting, fan curves, and MUX are not implemented. The test GPU reports current limit N/A, so watts setting is disabled.
- 120 offline tests passed, with macro input, advanced writes, and failure rollback simulated. This does not validate every application or hardware combination.

The bundle excludes development-machine settings, macros, passwords, logs, and diagnostics. Local macro settings/exports contain plaintext text; do not upload password macros.
